## Sharing Resources

You're already a member of the organisation, so you can contribute without forking. Here's how to upload a resource in the browser:

1. Go to the relevant module repo (e.g. [AI-Literacy](https://github.com/AI-for-Business-AfA/AI-Literacy)).
2. Navigate into the **topic folder** that matches your resource (e.g. `Prompt-Engineering/`).
3. Click **Add file** → **Upload files**.
4. Drag in your file (PDF, `.md`, link list, cheat sheet, etc.) and write a short commit message explaining what it is.
5. Click **Commit changes**.

Your file is now live and visible to everyone in the organisation.

**What's worth sharing?**

- Cheat sheets or prompt templates you found useful
- Articles or videos that explained a concept well
- Tool comparisons or evaluations you've done
- Your own notes or summaries from a topic

> **One rule:** place files in the correct topic folder so others can find them easily.
